Add the Combos, OP Champions, Buff/Nerf and Game modes screens, and the locales

Closes the gap against the reference's LoL route table (recovered with
tools/rea-routes.mjs: 108 routes, 14 of them League of Legends). The
reference's own sidebar also reaches /combos and /op-champions.

New screens
- Combos: a champion's skill history across patches, from
  desktop-api.op.gg/skill. The upstream payload is ~4.4 MB per champion, so
  the main process trims it to the 20 most recent versions and strips the
  HTML; the source text is Korean and is rendered verbatim.
- OP Champions: the tier-0 list. The upstream tier list has no tier 0, so the
  main process now promotes the top three of Tier 1 to "OP" — which is what
  the reference shows and what this screen lists.
- Buff / Nerf: the latest patch's champion changes, from
  desktop-api.op.gg/buff-nerf/latest.
- Game modes: the per-champion balance ratios, from
  lol-api-champion.op.gg/api/contents/aram-balance.

Chrome and assets
- The sidebar now matches the reference's DOM and copy: the Champions group
  (Tiers, Combos, OP Champions, Game modes, Buff / Nerf), the Direct group,
  the Discord item and the build stamp. A hash router was added so every
  screen is addressable.
- Axiforma is declared as a webfont and used for the app chrome; the product
  surface stays Roboto.
- Eleven locale catalogues are bundled and loaded lazily, with English as the
  synchronous fallback.

Fixes found while integrating
- Every image URL now pins the CDN's "latest" segment. The CDN lags the Data
  Dragon version, so a version-pinned champion path answers 403.
- tools/check-undefined.mjs: a static check for identifiers that are called
  but never defined. It found two real ReferenceErrors (primaryPosition and
  playsRole) that made the OP Champions screen render empty.
- tools/verify-pages.mjs now fails a page that renders its own error state.
